# Wuhhu

A simple static website published with GitHub Pages.

## Publish the site

1. Add `index.html` and this `README.md` to the top level of the `main` branch in [mzcheng1/wuhhu](https://github.com/mzcheng1/wuhhu).
2. Open the repository's **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then click **Save**.
5. Wait for the Pages deployment to finish. Your site will be at:

   <https://mzcheng1.github.io/wuhhu/>

## Make changes

Edit `index.html` to change the page. Add images and other files beside it, then link to them with relative paths, for example `<img src="images/photo.jpg" alt="Description">`.
